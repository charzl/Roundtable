# 0.2.1：Leader 与 AGY 参会更新

用户明确：会议选择一位 Leader，由 Leader 负责最后的 summary；AGY 同样参加独立调查，优先取得其意见，共享 MCP 接入继续单独完善。

## 实现

- 创建会议可选择一位已勾选参会者作为 Leader；参会列表标明 Leader，会议内可以更换并记录变更。旧 `summarizer` 数据和接口兼容，原有稿件作者不改写。
- 每次提示词标明该参会者的角色。结束时仅调度所选 Leader 读取全部公开报告、讨论和证据，生成保留优缺点、异议与未知项的最终总结；总结标记作者及 Leader 角色，用户决定单独保存。
- Codex、Claude、AGY 都可勾选参加独立调查，本机已安装的参会者默认勾选；三者都可选择为 Leader。移除 AGY 工具范围未验证造成的参与禁用，继续使用本项目文件读取限制、私有报告封存和齐备后统一公开。
- AGY 从提示词获取同一版本的会议材料，提示词明确项目共享 MCP 尚不可用。全局工具配置范围仍待适配，不能把参加成功等同于 MCP 已接通或严格工具隔离已验证。该范围选择已经由用户明确接受，无新增确认门槛。

## 真实三方验收

会议 `9537f4fd-e003-475b-98ac-e9d97b6622aa`，材料位于 `output/verification/three-independent-real/`，各调用原始文件在 `.roundtable/meetings/<ID>/calls/`。

- 三个真实 CLI 运行时的调查调用时间重叠、共同输入哈希一致，均提交有效报告；不是一位 provider 模拟三位。
- 三份报告统一公开，实际发言编号按 Codex、Claude、AGY 的参会顺序分配。
- 第 2 轮 Codex、Claude、AGY 各回应已公开意见；三者原文、观点与回应关系保留。
- Leader 选择为 Claude，最后一次调用是 Claude 的总结，输出作者、角色、引用通过校验。总计 7 次调用，全部成功；本次没有失败重试。
- 本场是对给定产品需求的推理分析，没有要求网络研究或代码实验。AGY 项目 MCP 状态继续记录为未验证；不证明三个底层模型一定不同。

独立调查与后续 Leader 总结已取得真实完成事件、有效结构、公开记录及原始输出。只启动进程或收到部分文字不计完成。

## 界面与兼容性验收

`npm test` 的 32 项测试通过，其中补充了 Leader 总结调用、更换与历史稿、旧版 `summarizer` 恢复检查。桌面与打包检查验证创建时选 Leader、会议中更换、身份标记、中英文和历史回放；隔离测试数据不作为真实参会证据。

三方真实记录回放材料位于 `output/verification/three-independent-desktop/`，显示三份报告、AGY 可选及默认勾选、Leader 下拉与身份、Leader Claude 最终总结，以及全部 7 次调用的完整导出。回放不启动模型。

重复真实调用会消耗账号额度：

```sh
npm run smoke:three-independent
```

不新增模型调用的界面检查需要本机已有上述会议：

```sh
node scripts/preview-three-independent.js
```
