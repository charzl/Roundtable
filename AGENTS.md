# Project scope

This is Roundtable (圆桌会议), an independent project for human and multi-agent meetings.

- Read `docs/product-brief.md` before proposing or implementing the first version.
- Keep all project work in this repository or its own Orca worktrees. Do not modify BabyLog.
- Preserve participant identity and distinguish real provider output from fixtures or demonstrations.
- Do not claim an agent has received a message, started a turn, or completed work without evidence.
- Use actual provider integrations; one provider impersonating multiple participants is not a real multi-agent meeting.
- Technology and provider integration choices remain open. Discuss them in this project's own session.
